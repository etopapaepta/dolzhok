# Должок

Браузерный хоррор от первого лица: четверо друзей едут ночью на дачу к Денису.
Поездка в машине, дача, которая меняется, когда на неё не смотришь.

**Играть:** откройте `index.html` или страницу GitHub Pages этого репозитория.

Управление: WASD — ходьба, мышь / стрелки — обзор, E — действие, F — фонарик, G — вкл/выкл постобработку.

Игра — один HTML-файл без зависимостей. Мультиплеер работает только со своим сервером (`/api`), на GitHub Pages — одиночная игра.
